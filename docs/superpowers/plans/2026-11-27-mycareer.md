# MyCareer (slice A) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. (Owner's project workflow: native execution in-session, then one fresh whole-branch review.)

**Goal:** Ship MyCareer slice A: build a player, draft night, play/sim seasons with in-game "you're open" moments, growth events, contract/trade/cut events, retirement and a templated epilogue.

**Architecture:** One optional `League.career` field (save v14) on the normal league. The followed player carries his max build and a **Career OVR** that the whole league reads as his OVR (the sim reads real attributes). In-game moments use **replay-pause**: sim, stop at an unanswered moment, ask, re-sim the same seed with answers locked in. Engine code lives in `src/engine/career/`.

**Tech Stack:** React + TypeScript + Vite, Vitest, pure-TS engine (`Rng`/`storyRng`, no `Math.random`), IndexedDB saves, sim worker.

**Spec:** `docs/superpowers/specs/2026-11-27-mycareer-design.md` (read it first; also `CLAUDE.md` and `2026-11-27-rivalries-design.md`).

## Global Constraints
- `GAMES_PER_SEASON = 40`; ratings are 25–99 across the 36 keys in `RATING_KEYS` (`SKILL_KEYS` excludes `intangibles`).
- Career OVR: fully maxed build reads exactly **99**; a fresh 19-year-old reads about **68**; start ratings = floor (25) + ~0.65–0.70 of the way to each max.
- POT is 99 until age 30 for the followed player (exempt from rivalry POT bump).
- **No odds shown anywhere**; moments show colour descriptors only (green "Wide open" / yellow "Decent look" / red "Contested").
- **Played games = full rewards, simmed = half**; simming never penalises. Contract decisions always pause, even when simming.
- Non-MyCareer games stay **bit-identical** to today; the box score always equals what was simmed.
- Moment trigger is a hash of (game seed, possession, attempt), never the main `Rng`; story randomness uses `storyRng`.
- The followed player's true league OVR is never shown or used; everything but the sim treats his OVR as Career OVR.
- Growth is permanent, explicit, logged, and capped by his max; temporary effects stay `GameMods`.
- Save is JSON-serializable; bump `League.version` to 14 and add a migration (`src/save/migrate.ts`, `CURRENT_VERSION`).
- GM-altering controls are hidden or read-only in MyCareer; viewing screens stay.
- Ship per `CLAUDE.md`: `npm test` and `npm run typecheck` green, push, merge to `main`, confirm the "Deploy to GitHub Pages" run is green.

## Review Focus
1. Unsigned/cut with no offers: a minimum deal is always available, the career never dead-ends (Task 10).
2. Followed player injured on a game day: that game auto-sims, no moment is asked (Task 7).
3. Reload mid-moment: the pending game and answers are saved so the same moment is asked again, not re-rolled (Task 7).
4. Simming an entire career with no plays: valid seasons, growth at half rate, a retirement and an ending, no stuck prompt (Task 11).
5. True OVR leak: no UI/engine path outside the sim reads `computeOvr` for the followed player (Task 3 sweep test).

export interface BuildTemplate { id: string; label: string; pos: Position; max: Ratings }
export const BUILD_TEMPLATES: BuildTemplate[]            // from player/archetype.ts roles, each spends exactly BUILD_BUDGET

### Task 6: Moment hook in the sim (replay-pause core)
**Files:** Create `src/engine/sim/moments.ts`; modify `src/engine/sim/game.ts`, `src/engine/events/mods.ts` (`GameMods.career?`); test `tests/engine/career.moments.test.ts`.
**Produces:**
```ts
export type MomentAnswer = { kind: 'shoot' } | { kind: 'pass'; to: string } | { kind: 'drive' }
export type Look = 'green' | 'yellow' | 'red'
export interface MomentOption { answer: MomentAnswer; label: string; look: Look }
export interface MomentPrompt { index: number; period: number; clock: number; score: { home: number; away: number }; options: MomentOption[]; clutch: boolean; rival: boolean }
export class MomentPause extends Error { constructor(public prompt: MomentPrompt) }
export interface CareerMods { playerId: string; rate: number; answers: MomentAnswer[]; auto: boolean }  // GameMods.career
export function momentTriggers(seed: number, possNo: number, attempt: number, rate: number): boolean  // hash, no Rng
export function lookFor(p: number): Look   // green >= 0.45, yellow >= 0.30, else red (tunable constants, monotonic)
```
In `simGame`, when `mods.career` is set and the followed player is the selected shooter and `momentTriggers` fires (rate boosted in clutch/rival/playoffs): count the moment; if an answer exists apply it (`shoot` = normal; `pass` = reselect shooter as that teammate; `drive` = force `layup`/`driveDunk` zone); if not and `auto` is false throw `MomentPause`; if `auto` is true use the highest-look option (ties: shoot). Place the hook after the shot probability `p` is known so `lookFor(p)` is derived from the same maths (extract the zone-probability code into a local closure only if golden stays identical).
